# AdBlogger

React-приложение на Vite.

## Установка
npm install

## Запуск в режиме разработки
npm run dev

### После запуска приложение доступно по адресу:
http://localhost:5173

## Production-сборка
npm run build

### Собранные файлы находятся в директории:
dist/

### Предпросмотр production-сборки
npm run preview
